#📘 Day 3 - Array Operations

## 📖 What are Array Operations?

Array operations are the different actions performed on elements of an array.

Common operations:

- Insertion
- Deletion
- Searching
- Updating
- Reversing

## 1. Insertion

Insertion means adding a new element at a specific position in an array.

## 2. Deletion

Deletion means removing an element from an array.

## 3. Searching

Searching means finding a particular element in an array.

Linear Search checks elements one by one.

## 4. Updating

Updating means changing the value of an existing element.

## 5. Reversing

Reversing means changing the order of elements.
